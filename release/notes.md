# v3.27.1

## 修复

- 修复「客户端身份」未覆盖 Desktop 自动 Git 上下文版本的问题：`appVersion` 和 `appServerVersion` 与请求头使用同一份客户端身份，复用在线更新、固定版本及 Client Key 独立配置，覆盖 HTTP 和 WebSocket 请求
- 隐私预设保留实际仓库、提交 hash、分支和工作区标识，仅归一化个人路径；移除重复的 Desktop 身份预设和版本快捷项，避免生成虚假的项目状态

## 升级说明

- 已保存的隐私规则不会自动改写。若已添加旧预设，请移除其中固定仓库、提交、工作区标识和版本号的步骤，或删除旧规则后重新添加当前预设；客户端版本统一由「客户端身份」管理
