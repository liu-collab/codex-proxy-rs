# v3.37.2

## CPR 互联

- 支持通过专用 API Key 公开获准共享的预算、账号池、额度与套餐信息，共享默认关闭，范围受 Key 分组与模型权限限制
- OpenAI 兼容 API Key 账号可自动发现上游 CPR 互联能力，账号列表与详情显示已保存的观测，支持手动刷新和大账号池额度查看
- 上游明确返回 Key 预算耗尽时暂停对应账号，后续同步确认可用后恢复；普通限流冷却独立处理，不根据余额推断账号资格
- 优化大账号池的额度导出、代理关联查询和图表绘制，避免管理查询反复读取完整快照

## 账号与管理界面

- 支持编辑账号名称，留空时使用邮箱展示；修复订阅标识、额度窗口及套餐信息的展示
- 账号、代理、分组及设置表单统一使用字段级校验，空值校验与范围、格式限制分开，避免空输入同时出现范围错误
- 用量统计、缓存命中与平均 TTFT 的缺失值统一显示 0，查询刷新保留统计数值，补齐请求健康时间线空状态
- 改善侧栏选中项、表格展开行、日期选择器和提示浮层的过渡，修复复选框操作误选相邻文字的问题
- 固定 UI 组件库 v0.8.0，统一主题命名空间与公开主题 API，Markdown 内容支持 GitHub 提示块

## 模型能力与默认设置

- 适配模型目录分别声明推理强度和推理摘要支持，避免仅支持推理强度的模型被客户端发送不支持的摘要参数
- 初始账号并发改为 3，Key 与账号等待队列各为 10，Guardian 保留并发为 5；已保存的运行设置保持原值，仍处于初始版本且完全匹配旧默认值的配置同步更新

## 升级事项

- 从 v3.36.0 升级会执行新增的 0035 数据库迁移，已发布的 0034 及更早迁移保持不变
- 曾部署未发布的早期 `main` 构建并执行 `0035_cpr_link.sql` 的实例，需要先核对迁移来源与校验和；该迁移在本轮开发中发生过调整，不能直接按正式版升级路径处理
- 插件工作台需配套升级至 v0.9.0，旧版工作台使用的 `cp` 主题变量与本版宿主的主题桥不兼容
- 插件适配器支持 `reasoning.summary` 时需显式声明 `ModelPresentation.reasoning_summary`；省略该字段表示不支持摘要，不影响推理强度档位
