# v3.35.0

## 升级事项

- 账号过载保护替换为通用错误保护，数据库迁移会删除旧 `accountAutoFreeze*` 设置，不转换规则或继承参数；升级后默认关闭、规则为空，需要在「系统设置 → 运行设置 → 错误保护」重新配置并启用，管理 API 客户端须改用 `accountErrorProtection`
- 已有账号冻结保留当前冷却截止时间，保护关闭时到期解除；移除自动下调账号并发上限的逻辑，已经保存的并发上限保持原值，需要恢复时请手动调整
- 插件模型目录仅支持 `model_catalog` v2，v1 插件升级后无法正常启用；插件作者须声明 `model_catalog.version = 2`，将直接别名放入 `aliases`，并同时返回 `models` 数组，没有适配模型时使用空数组

## Chat Completions 接入

- 新增 `POST /v1/chat/completions`，将 Chat 消息转换为 Responses 执行，支持 JSON 与 SSE、完整消息历史、图片输入、function 工具调用、结构化输出和可选用量块，可通过官方 OpenAI SDK 的 Chat 方法接入
- 复用现有账号路由、权限、重试、计量和取消流程；不支持的已知语义明确拒绝，推理密文回放与图片输出仍需使用原生 Responses 接口
- HTTP 插件读取 Chat 请求与响应，request/attempt 插件读取转换后的 Responses；按路径匹配请求的插件需将 `/v1/chat/completions` 纳入匹配范围

## 账号保护与用量统计

- 错误保护支持按平台、上游状态码、错误码、错误类型和错误信息组合规则，覆盖 OpenAI、xAI 与受管上游适配器；同一次失败命中多条规则只累计一次，支持冻结原因展示、到期探测与手动恢复
- 用量性能洞察新增平均并发与峰值并发趋势，按逻辑请求执行区间统计，重试不重复计数；同时展示准入判定与账号选择等待耗时
- 修复 Codex 会话内更新推理强度后，用量记录仍显示旧档位的问题；支持原生续接继承已观测的配置更新，不改写上游请求

## Codex 连接与客户端配置

- 上游 WebSocket 改为被动回复 Pong，下游 WebSocket 独立探活；修复客户端断开、重新绑定及跨客户端续接时的连接释放与控制收发归属，保留活跃客户端跨轮续接
- 新增 `openai.ws_pool.idle_timeout_ms`，默认 300000 毫秒，回收未绑定活跃客户端的空闲上游 WebSocket；心跳不延长空闲期限，正在生成的响应不因空闲回收而中断
- 管理端生成的 Codex 配置补充模型目录地址与语音控制地址，使模型发现和语音控制连接使用配置的网关；Live 语音选号排除已明确标记为 Free 的 OAuth 账号
- Codex CLI 最低版本限制覆盖官方 TUI、exec、IDE、SDK、App Server 和 MCP 客户端，按 User-Agent 中的 Core 版本检查，版本比较忽略构建元数据

## 管理端与日志

- 未保存语言偏好时默认使用简体中文，保留已有语言选择，并简化登录文案
- 账号、插件、用量及客户端配置等页面的加载失败改用通知反馈，调整空状态与加载交互；首页 API Key 账号名称下方展示备注
- 修复禁用日志目标的探测影响后续警告日志输出的问题
